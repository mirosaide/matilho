# Changelog

## [1.0.0] — 2025-11-11

Versão inicial pública.

### Funcionalidades
- Anotação de bounding boxes com canvas interactivo
- Suporte a múltiplas classes com cores personalizáveis
- Exportação em YOLO, COCO JSON e Pascal VOC
- Augmentação automática de dados (flip, brilho, contraste, ruído, crop)
- Quality Check por Variância do Laplaciano — detecção de imagens desfocadas
- Persistência total entre sessões via IndexedDB + localStorage
- Undo/redo com histórico de até 60 estados
- Zero dependências de runtime — funciona offline
