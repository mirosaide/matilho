# Security Policy

## Scope

O Matilho corre inteiramente no browser do utilizador. Não tem servidor, não envia dados para lado nenhum, e não processa ficheiros remotos. A superfície de ataque é limitada à manipulação de ficheiros locais via File API.

## Reporting a Vulnerability

Se encontrares uma vulnerabilidade (ex: XSS via nome de ficheiro, manipulação maliciosa de ficheiros de anotação), reporta em privado antes de tornar público:

**Email:** mirosaide@gmail.com  
**Assunto:** `[SECURITY] Matilho — <descrição breve>`

Respondo em 48 horas. Se a vulnerabilidade for confirmada, publico um fix e credito o reporte no CHANGELOG.

Não abras um issue público antes de receberes resposta.
